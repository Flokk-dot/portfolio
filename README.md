# Felipe — Portfólio

Portfólio profissional de **Felipe**, Desenvolvedor de Software focado em aplicações web,
sistemas internos, automação e soluções com Inteligência Artificial.

## Visão do projeto

O site apresenta uma seleção de projetos reais em uma experiência direta, acessível e
responsiva. A linguagem visual combina azul-marinho e off-white, com uma ilustração original
no hero e movimentos discretos.

### Projetos apresentados

- Fabrinox Logística
- Morble
- Plataforma de Ergonomia
- Fabrinox E-commerce
- Automação de Marketplaces

## Executar localmente

O projeto não exige instalação de dependências. Abra `index.html` no navegador ou use um
servidor estático local.

## Estrutura

```text
portfolio/
```
